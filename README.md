# Emotion Detection Web Application

## Project Overview

This project is an AI-powered Emotion Detection Web Application developed as part of the IBM Skills Network final project.

The application analyzes a user's text using the Watson NLP Emotion Detection service and identifies five emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

The application also determines the dominant emotion based on the emotion with the highest score.

## Technologies Used

- Python 3.11
- Flask
- Watson NLP Emotion Detection
- Requests
- JSON
- HTML
- JavaScript

- Pylint
